Modo TDAH: o que muda

  1. Aparece a aba Meus projetos: um cartão por projeto, com barra de progresso.
  2. Os projetos com prioridade alta ficam no topo.
  3. Projeto novo nas suas pastas aparece sozinho, marcado como novo.
  4. Se um nome parece com outro projeto, o cartão avisa. Antes de criar um projeto, digite o nome e pergunte se já existe parecido.
  5. Projeto parado há mais de 2 horas: o modelo do seu PC resume os últimos commits no cartão.
  6. Botão Copiar contexto: um texto curto para colar no Claude e retomar o projeto sem gastar tokens explicando.
  7. Uma vez por semana: resumo curto de todos os projetos, para o Claude sugerir prioridades.
